The filing cabinet

Each area is a drawer. Swipe sideways to the next drawer and you look down onto its hanging files. The files hang in A to Z order with every tab lined up on the left. Scroll to look through them, and tap one to open it. Try it on the phone below.

How it moves

Sideways
Closes this drawer and slides the next one open: Everything, then each of your areas, then Unsorted. The brass label on the drawer front names the area. The row of labels underneath lets you jump straight to any drawer.
Up / down
Scrolls through the hanging files, A to Z. Every tab sits in the same place, so the names read straight down like a list. Nothing moves on its own while you scroll.
Tap
Opens that file in place, so the files below it slide down. Tap the open file again to pick it.
Find
Takes the files that don't match out of every drawer. Each drawer front shows how many are left.
Wide screen
On a computer, the drawers sit open side by side, so you don't need to swipe.

Where it goes

Focus"Which project?" The drawers replace the sideways folder strip that showed one folder at a time.
Sort"Which folder?" uses the same drawers when you file a thought.
ProjectsThe same drawers, with each project's progress bar printed on its file. Switch the phone to Projects to see it.
