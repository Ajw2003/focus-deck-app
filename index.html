How it works

  1. Jot it down

    A stray thought goes on the notepad. It waits in your in-tray until you are ready.

  2. Pick the kind of work

    Flip through your folders and index cards. Choose where the thought belongs.

  3. Get one task

    It lands on the desk as a sticky note. Tick it off, or slip it back for later.

Install it

Installing is optional. It makes Focus Deck open in its own window, or from your home screen, like any other app. It works the same in a browser tab.

  1. Tap Open in your browser above. Use Safari. The Home Screen option only works from the app page.
  2. Tap the Share icon.
  3. Tap Add to Home Screen.
  1. Open this page in Chrome.
  2. Tap the ⋮ menu.
  3. Tap Install app or Add to Home screen.
  1. Open this page in Chrome or Edge.
  2. Click the install icon at the right end of the address bar. It looks like a monitor with a down arrow. Or use the ⋮ menu and choose Install Focus Deck.
  3. It opens in its own window, with an icon in your taskbar or dock.

Opera on a computer cannot install web apps. There is no install button in the address bar. Its own "Create desktop shortcut" only opens a normal Opera tab. To get an installed app, open this page in Edge or Chrome and install from there. Opera on Android is fine: use Add to Home screen.

Firefox on a computer does not install web apps either. Use Focus Deck in a tab, or install it from Edge or Chrome.

Do I need GitHub?

To use it on one device: no

Everything stays in this browser. There is nothing to sign up for.

To sync between devices: yes

Focus Deck uses your own free GitHub account to store a private copy of your tasks. The app walks you through it in about five minutes.

Your access key (GitHub calls it a token) stays in your browser. It is only ever sent to GitHub.

If you write code: an extra

You can link tasks to GitHub issues, so the task you are putting off lives in one place.
